# LUMI — Room Scent Website + Mini POS

โปรเจกต์นี้เป็นการต่อยอดจากเว็บไซต์ LUMI เดิม ไม่ได้สร้างเว็บใหม่แยกออกมา โดยเพิ่มระบบ POS สำหรับงาน Week 8 และเชื่อมการนำทางกับหน้าเดิม

## หน้าเว็บ
- `index.html` หน้าแรก LUMI
- `product.html` แสดงสินค้าและเลือกกลิ่น
- `order.html` แบบฟอร์มสั่งซื้อ
- `thankyou.html` หน้ายืนยันคำสั่งซื้อ
- `admin.html` ดูคำสั่งซื้อจาก localStorage
- `pos.html` ระบบ POS: ขายสินค้า ตัดสต๊อก ดูยอดขาย ประวัติการขาย และดูคำสั่งซื้อจากหน้าเว็บ
- `products.json` ข้อมูลสินค้ากลางที่ใช้ร่วมกัน
- `script.js` การแสดงสินค้าและระบบสั่งซื้อ
- `style.css` รูปแบบเว็บไซต์เดิม

## วิธีใช้งาน
เปิดผ่าน Vercel หรือ Live Server แล้วเข้า `pos.html`
ข้อมูล POS เป็นข้อมูลเดโมที่เก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น

## จุดที่ต่อจากเว็บเดิม
- ใช้ชื่อแบรนด์ LUMI และข้อมูลสินค้าเดิม
- หน้า Product ส่งสินค้าไปหน้า Order เหมือนเดิม
- เพิ่มเมนู POS ใน Navigation
- POS อ่านรายการสินค้าจาก `products.json` เดียวกับหน้า Product/Order
- POS แสดงคำสั่งซื้อที่บันทึกจากหน้า Order
